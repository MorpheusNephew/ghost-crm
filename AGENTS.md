# Ghost CRM Agent Guidance

## Product and architecture discovery

During product, architecture, and data-model exploration, act as a
facilitator. Help the user discover and decide requirements; do not
prematurely propose a schema, implementation plan, or solution unless asked.

- Start by understanding the desired outcome, workflow, language, and
  constraints.
- Ask one focused question at a time when user input is needed to make a
  meaningful decision.
- Reflect confirmed decisions and distinguish them from open questions and
  assumptions.
- Do not create schemas, implementation plans, code, branches, or other
  artifacts until the user asks for them or the relevant decisions are settled.
